# Shortsrator 최종 목표

## 최종 목표 (1문장)
테마 규칙 기반으로 사람이 컨펌 게이트 4곳에서만 개입해, 유튜브 숏츠 1편을 로컬에서 반자동 생산하는 파이프라인을 완성한다.

## 성공 기준 (측정 가능)
1. 파일럿 "판테온 돔" 15초 5컷 1편이 게이트 4개를 모두 거쳐 최종 mp4로 완주된다 (REQ-PILOT-01)
2. 모든 컷 길이가 TTS 실측 오디오 길이와 일치한다 — 오디오/영상 싱크 어긋남 0건 (REQ-TTS-01, REQ-ASM-01)
3. 이미지·영상 생성이 Higgsfield API 어댑터로 자동 호출되고, 설정 전환만으로 MANUAL 어댑터로 폴백된다 (REQ-ADAPT-01)
4. 파이프라인 전 단계 프롬프트에 "신비한 건축" 테마 규칙이 자동 주입된다 (REQ-THEME-01)
5. 편당 사람 개입 시간 60분 이내로 파일럿 완주

## 마일스톤
- M1 — 목업 승인: 파이프라인 UI(에피소드 진행 화면·컨펌 게이트) 목업이 사용자 승인됨
- M2 — MVP 동작: 파일럿 1편이 파이프라인으로 완주됨 (성공 기준 1·2·3·4 충족)
- M3 — 완성: P2 업로드 연동까지 붙어 생산→업로드가 한 흐름으로 동작, 편당 60분 이내(성공 기준 5)
