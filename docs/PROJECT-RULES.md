# PROJECT-RULES — 프로젝트 전용 규칙

이 파일은 **프로젝트 소유**다. 템플릿 동기화(`/template-update`)는 `docs/`를 절대 건드리지 않으므로, CLAUDE.md가 템플릿 버전으로 덮어써져도 여기 적은 규칙은 살아남는다.

- 파생 프로젝트는 여기에 자기 전용 규칙을 쌓는다 — 스택 선택, 도메인 규칙, 팀 컨벤션 등.
- 템플릿 원본에서는 빈 플레이스홀더로 유지한다.
- CLAUDE.md의 `@docs/PROJECT-RULES.md` import가 깨지지 않도록 이 파일은 반드시 존재해야 한다 — 비우더라도 삭제하지 않는다.
