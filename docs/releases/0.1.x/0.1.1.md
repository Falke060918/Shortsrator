# 0.1.1 — 2026-08-20

진행 현황판에 "누가 한 일인지"가 보이도록 하고, 마무리 보고를 실제로 일한 담당이 직접 남기게 바꿨다. 설정을 다시 손볼 일은 없다.

## [RN-0014] 현황판 각 줄에 누가 하는 일인지 표시

- 기존: 현황판에는 작업 이름만 떠서, 같은 방에서 도는 일인지 따로 떼어낸 작업 공간에서 도는 일인지 구분할 수 없었다.
- 페인포인트: 줄이 여러 개 뜨면 누구 것인지 몰라 어느 화면을 봐야 하는지 매번 되짚어야 했다.
- 개선: 줄마다 짧은 표시가 붙는다 — 본체는 `[M]`, 옆에서 돕는 담당은 `[S]`, 따로 떼어낸 작업 공간은 `[W1]`처럼 번호가 붙고, 같은 공간을 맡긴 담당과 그 안에서 일하는 담당은 `[S/W1]`처럼 같은 번호로 짝지어 보인다.

## [RN-0015] 마무리 보고를 실제로 일한 담당이 직접 남기도록 변경

- 기존: 따로 떼어낸 작업 공간의 일은 그 일을 맡긴 쪽이 대신 "끝남"을 적어줬다.
- 페인포인트: 맡긴 쪽이 자리를 비우거나 연결이 끊기면 이미 끝난 일이 현황판에서 영원히 "검증 중"으로 남았다.
- 개선: 안에서 일하는 담당이 시작부터 마무리까지 자기 손으로 적고, 맡긴 쪽은 처음 한 번과 담당이 끝내 적지 못했을 때의 뒷수습만 맡는다.

## [RN-0016] 현황판 메모에 단계 대신 '무슨 일인지'를 적도록 통일

- 기존: 메모 칸에 "검증 중"이나 "작업완료"처럼 단계를 적는 예시가 섞여 있었다.
- 페인포인트: 단계는 바로 왼쪽 칸에 이미 나와 있어서, 같은 정보가 두 번 나오고 정작 무슨 일인지는 알 수 없었다.
- 개선: 메모에는 "가져오기 기능 개선"처럼 무슨 일인지만 적도록 규칙과 예시를 전부 맞췄다. 실패했을 때만 무엇이 막았는지를 적는다.

## [RN-0017] 외부에서 가져온 문서에 비밀정보가 섞일 수 있다는 경고 추가

- 기존: 다른 곳의 문서를 이 프로젝트로 가져오는 기능에는 별도 주의 문구가 없었다.
- 페인포인트: 가져온 내용에 열쇠(비밀번호·접속키)나 개인정보가 섞여 있으면 그대로 저장소에 올라갈 수 있었다.
- 개선: 가져오기 전에 비밀정보·개인정보를 확인하도록 경고를 넣고, 이미 올라갔다면 열쇠를 새로 바꾸라는 안내까지 함께 표시한다.

## [RN-0018] 템플릿 동기화가 두 번 돌아야 반영된다는 사실을 안내문에 명시

- 기존: 동기화 도구의 안내문이 실제 동작보다 오래돼, 한 번만 돌리면 다 반영되는 것처럼 읽혔다.
- 페인포인트: 첫 번째 실행 결과만 보고 "빠졌다"고 오해해 원인을 찾는 데 시간을 썼다.
- 개선: 첫 실행은 옛 도구가 돌기 때문에 새 내용은 두 번째 실행부터 적용된다는 점을 안내문에 그대로 적어뒀다. 도구가 하는 일 자체는 바뀌지 않았다.

## 파생 프로젝트 영향

없음 — 동기화만 하면 된다. 파생 프로젝트(이 템플릿을 복사해 만든 다른 프로젝트)는 동기화 후 프로그램을 한 번 껐다 켜면 새 규칙이 적용되고, 설정을 따로 손볼 일은 없다. 예전 방식으로 남은 현황판 기록도 그대로 보인다.
