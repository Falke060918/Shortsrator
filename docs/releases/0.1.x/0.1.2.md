# 0.1.2 — 2026-08-20

작업 현황판의 마감 표시를 다듬고, 가져오기 기능을 안전하게 보강하고, 자동장치들이 실제로 동작하는지 일제 점검한 버전.

## [RN-0019] 작업 현황판에 '반영' 단계 추가

- 기존: 작업이 끝난 것과 그 결과가 저장소에 최종 반영된 것을 현황판이 구분하지 못했다.
- 페인포인트: "완료"로 보이는 작업이 실제로 합쳐졌는지는 따로 확인해야 알 수 있었다.
- 개선: 병합까지 끝난 작업은 ◆ 반영으로 따로 표시된다.

## [RN-0020] 끝난 줄은 1분, 멈춘 줄은 1시간 뒤 사라짐

- 기존: 끝났거나 버려진 작업 줄이 6시간 동안 화면에 남아 있었다.
- 페인포인트: 지나간 작업이 현황판을 차지해 지금 진행 중인 일이 한눈에 안 들어왔다.
- 개선: 끝난 줄은 1분, 갱신이 멈춘 줄은 1시간 뒤 사라져 진행 중인 일만 남는다.

## [RN-0021] 가져오기 기능 안전 보강

- 기존: 다른 프로젝트에서 내용을 가져올 때 개인 설정 파일이 함께 커밋되거나 기존 기록이 경고 없이 덮어써질 수 있었다.
- 페인포인트: 가져오기 한 번에 개인 정보 유출이나 기록 유실이 생길 수 있었다.
- 개선: 개인·로컬 파일 제외, 커밋 전 검사, 기존 기록 백업 단계가 추가됐다.

## [RN-0022] 자동장치 실동작 일제 점검

- 기존: 훅(자동 실행 장치)·허용목록·가져오기·파생 프로젝트 갱신이 문서상으로만 검증돼 있었다.
- 페인포인트: 문서와 실제 동작이 어긋나도 실사용 전까지 알 수 없었다.
- 개선: 전부 실제로 돌려 확인했고, 결과 보고서와 권한 설정 보강안을 산출했다.

## 파생 프로젝트 영향

없음 — 동기화만 하면 된다. 파생 프로젝트(이 템플릿을 복사해 만든 다른 프로젝트)는 `/template-update` 한 번으로 새 현황판 동작과 가져오기 보강을 그대로 받는다.
