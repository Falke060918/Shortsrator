# 0.0.2 — 2026-08-19

일을 여러 창에 나눠 맡길 때, 지시가 상대에게 실제로 전달되지 않은 채 "잘 넘어갔다"고 보이던 문제를 막았다.

## [RN-0008] 나눠 맡긴 작업 창에 지시가 실제로 전달되도록 수정

- 기존: 다른 작업 창에 지시문을 넘길 때 글자는 입력칸에 찍히지만 전송(엔터) 없이 그대로 남는 경우가 있었고, 넘기는 쪽에는 성공으로 보고됐다.
- 페인포인트: 상대는 아무 일도 시작하지 않은 채 멈춰 있는데 겉으로는 정상이라, 한참 뒤에야 알아채고 다시 넘기느라 매번 몇 분씩 날렸다.
- 개선: 지시를 넘길 때 전송까지 함께 하도록 규칙에 못박고, 1분 뒤 확인에서 "글자만 남고 시작 안 함"을 고장 신호로 명시해 바로 잡아내게 했다.

## [RN-0009] 명령 사용법은 추측 대신 공식 안내서를 먼저 확인

- 기존: 명령을 어떻게 쓰는지 불확실하면 짐작해서 실행하거나 다른 담당에게 다시 물어보곤 했다.
- 페인포인트: 정작 프로그램이 정확한 사용법 안내서를 자체적으로 갖고 있는데도 그걸 안 보고 왕복하느라 시간을 버렸다.
- 개선: 사용법이 헷갈리면 짐작하거나 다시 맡기기 전에 그 안내서부터 확인하도록 순서를 규칙에 적어뒀다.

## 파생 프로젝트 영향

없음 — 파생 프로젝트(이 템플릿을 복사해 만든 다른 프로젝트)는 동기화만 하면 된다. 다만 여러 창에 일을 나눠 맡기는 방식을 쓰고 있었다면, 동기화 전까지는 지시가 전달되지 않고 멈추는 증상이 그대로 남는다.
